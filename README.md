# A Comparative Analysis of Predictive Performance and Interpretability in Time Series Forecasting Models

A reproducibility-supported evaluation pipeline that compares selected
time-series forecasting models under identical experimental conditions on
the ETTh1 dataset. This repository accompanies a Bachelor thesis at the
FH Technikum Wien.

The thesis frames the artifact as a *reproducibility-supported, fairness-oriented
evaluation pipeline for selected time-series forecasting models under
controlled experimental conditions* — not as a single-model benchmark and
not as a metric-table comparison. The thesis text is submitted to the
university and is not redistributed via this repository.

## Research questions

- **RQ1.** Under identical task, dataset, preprocessing, and evaluation
  conditions, how do selected forecasting models differ in predictive
  performance?
- **RQ2.** Under a common post-hoc explanation protocol, how do the selected
  models differ in explanation faithfulness and rank agreement?
- **RQ3.** Under the same experimental conditions, is there evidence of a
  performance–interpretability trade-off for the selected models and
  criteria?

## Experimental setup

- **Dataset.** ETTh1 (17 420 hourly observations, seven numerical
  variables) — `data/ETTh1.csv`.
- **Split.** Chronological 60 / 20 / 20 train / validation / test.
- **Scaling.** `StandardScaler` fitted on the training partition only;
  applied to validation, test, and the inverse-transform step.
- **Windowing.** Sliding windows of length 96 + 24 are constructed
  separately within each split.
- **Task.** 96-hour input window → 24-hour direct multi-step forecast on
  all seven variables jointly (multivariate target).
- **Core models.** Linear Regression (LR), MLP, LSTM, Temporal Fusion
  Transformer (TFT). LR is fitted once as a deterministic closed-form
  baseline; MLP, LSTM, and TFT are trained across five stochastic seeds
  ({42, 123, 456, 789, 1024}).
- **Reporting.** Final metrics (MSE, MAE, RMSE) are reported in the
  original data scale; diagnostic scaled metrics are also retained as
  intermediate artifacts. Uncertainty is reported via paired moving-block
  bootstrap (block length L = 96).
- **Interpretability.** Primary cross-model comparison uses occlusion
  importance, AOPC, and rank agreement. SHAP outputs for LR / MLP / LSTM
  and architecture-native VSN / `interpret_output` for TFT are retained
  only as auxiliary, method-specific artifacts.

## Reproducibility

The repository supports automated artifact-level verification, not
bit-level reproducibility across machines. The verification script
checks shape, finiteness, presence, and SHA256 manifest coverage of the
primary pipeline artifacts and (in `--mode full`) of bounded auxiliary
SHAP outputs.

```bash
# 1. Create the conda environment
conda env create -f environment.yml
conda activate thesis
pip install -e .

# 2. Run the test suite
pytest tests/

# 3. Regenerate result tables and figures from the active CSVs
python scripts/regen_tables.py
python scripts/make_figures.py --all

# 4. Run the artifact-level verification
python scripts/verify_end_to_end_reproducibility.py --mode core
```

The `Makefile` exposes the same workflow under shorter targets
(`make test`, `make smoke`, `make tables`, `make verify-core`, …).
Run `make help` for the full list.

A complete retraining run (`make train` followed by `make analyze`)
requires a CUDA-capable GPU; the recorded development environment used
an NVIDIA RTX 5080 Laptop GPU. Without a GPU, the deterministic LR path
still runs end-to-end on CPU.

## Caveats

All numerical results reported here come from the ETTh1 dataset under
the fixed experimental setup described above. Findings should be read
within this configuration: the comparison is bounded by the selected
models, the chosen metrics, and the locked tuning protocol. The
interpretability analysis reports model-level explanation behaviour
under the chosen criteria; it does not establish causal variable
relevance in the underlying physical system.
